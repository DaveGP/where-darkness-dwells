required, but the authors are listed here. `GameAudio` loads these files from `Resources/Audio` by name.

## Effects (`Resources/Audio/Effects`)

All from Kenney (https://kenney.nl), CC0 (`Kenney-License.txt`): the RPG Audio, Impact Sounds and Interface Sounds packs.
Each file is renamed after the moment it plays; a number after the name marks a variant, and variants take turns.

| Name | Plays when | Kenney file |
| --- | --- | --- |
| `swing` | A hero or enemy strikes | knifeSlice, knifeSlice2, chop |
| `ready` | A hero is activated | drawKnife1 to 3 |
| `hit`, `heavy` | A blow lands (heavy: 10 or more) | impactPunch_medium_000 to 002, impactPunch_heavy_000 to 001 |
| `clang` | Block stops a whole blow | impactMetal_medium_000 to 001 |
| `guard` | Block is gained | impactPlate_light_000 to 001 |
| `fall` | A fighter goes down | impactWood_heavy_000 to 001 |
| `heal` | Healing | glass_001, glass_002 |
| `curse` | A status lands | scratch_001, scratch_002 |
| `cards` | Cards are drawn mid-turn | bookFlip1, bookFlip2 |
| `discard` | A card is discarded | cloth1 |
| `won`, `lost` | A fight ends | confirmation_004, error_008 |
| `door` | A room is entered | doorOpen_1, doorOpen_2 |
| `journal_open`, `journal_close` | The journal | bookOpen, bookClose |
| `click` | Any button | click_002 |
| `refused` | A command is refused | error_004 |
| `take_card` | A reward card joins the deck | bookPlace1 |
